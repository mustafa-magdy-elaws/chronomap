# ChronoMap: a map-based planning approach

ChronoMap is a map-based planning approach for linear infrastructure: the Primavera P6 schedule played on the real site map, day by day.

Developed by **Mostafa Magdy ElAws** (Planning & Risk Manager, PMP), Jeddah, Saudi Arabia.
